## 🛠️ Technology Stack

- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Custom properties (CSS variables), Flexbox, Grid, keyframe animations, backdrop blur.
- **Vanilla JavaScript (ES6+)**: Clean, lightweight script handling menu toggles, scroll spies, dynamic navbar elevation, and form feedback.
- **Google Fonts**: `Plus Jakarta Sans` & `JetBrains Mono`.
