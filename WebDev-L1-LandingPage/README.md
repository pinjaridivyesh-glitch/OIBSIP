## 🚀 Key Features

- **Fixed / Sticky Navigation Bar**:
  - Seamlessly remains pinned at the top on scroll with frosted glass backdrop blur (`backdrop-filter: blur(16px)`).
  - Includes 6 navigation targets: *Home, Features, Tech Specs, Reviews, Pricing, Contact* + CTA button.
  - Fully responsive with pure CSS hamburger mobile navigation menu.

- **Hero Section**:
  - High-impact typography with headline, subheadline, and primary/secondary CTA buttons.
  - Live animated pulse badge showcasing product release status.
  - Custom vector/SVG illustration of the headphones with acoustic wave rings.
  - Dynamic floating micro-badges for Hi-Res audio, rapid charging, and ergonomic seal.
  - Numerical metrics counter highlight (48dB ANC, 65h battery, 4.9★ rating).

- **Feature Highlights (CSS Grid)**:
  - 6 interactive cards with custom SVG icons and dedicated accent color glows.
  - Highlights: *48dB Adaptive Hybrid ANC, 40mm Beryllium Drivers, 65-Hour Battery Life, 360° Spatial Audio Tracking, Bluetooth 5.4 Multipoint, and Ultra-Plush Vegan Leather*.

- **Engineering Tech Specs & About**:
  - Split-column layout featuring acoustic metrics (THD < 0.05%, 20ms latency, 250g weight).
  - Complete hardware specification breakdown table covering drivers, codecs, waterproofing, and mics.

- **Testimonials Section**:
  - 3 detailed customer reviews featuring 5-star ratings, author avatars, and industry credentials.

- **High-Converting Pre-Order Pricing Card**:
  - Clear discount pricing display ($299 vs $399 MSRP).
  - Benefit checklist (30-day money back guarantee, free worldwide shipping, 2-year warranty).

- **Contact & Inquiry Section**:
  - Interactive inquiry form with input states and focus rings.

- **Footer with Social Icons**:
  - Rich 4-column footer containing brand info, navigation links, Oasis Infobyte task links, and GitHub / LinkedIn / Twitter SVG icons.

## 🎨 Design System

- **Color Palette**:
  - Background: Deep Void Slate (`#090d16` to `#05070c`)
  - Cards: Semi-transparent glass (`rgba(18, 26, 43, 0.75)`) with `1px solid rgba(255, 255, 255, 0.08)`
  - Primary Accent: Neon Electric Cyan (`#38bdf8`)
  - Secondary Accent: Royal Indigo (`#818cf8`)
  - Tertiary Accent: Soft Purple (`#c084fc`)
  - Text: Polar White (`#f8fafc`) and Muted Slate (`#94a3b8`)
- **Typography (Google Fonts)**:
  - Display / Headings: `Outfit` (Weights: 600, 700, 800)
  - Body / UI: `Plus Jakarta Sans` (Weights: 400, 500, 600)
- **Responsive Design**:
  - CSS Flexbox & CSS Grid
  - Fluid typography with `clamp()`
  - Tested across Mobile (360px - 480px), Tablet (768px), and Desktop (1024px - 1440px)
  - Zero content overlap or horizontal scrollbars

## 🛠️ Technology Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`, `<figure>`)
- **CSS3**: Variables, Flexbox, Grid, Keyframe Animations, Backdrop Filter, Glassmorphism
- **No external JavaScript libraries**: 100% pure lightweight CSS interactions
